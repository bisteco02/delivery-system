## 📞 LIGAÇÃO TELEFÔNICA (Fria)

### Abertura (10 segundos)
```
"Bom dia! Meu nome é [SEU NOME], tudo bem?
Estou ligando para o responsável pela [NOME DA PADARIA].
Poderia falar com ele(a) rapidinho?"
```

### Se Perguntar "É sobre o quê?"
```
"É sobre um jeito simples de aumentar as vendas da padaria
colocando o cardápio na internet. Leva só 2 minutinhos,
pode ser?"
```

### Pitch Inicial (30 segundos)
```
"Olá Sr(a) [NOME]! Deixa eu ser direto(a):

Eu criei um sistema que coloca o cardápio da sua padaria
na internet em 10 minutos. Funciona assim:

1. Seus clientes acessam pelo celular
2. Veem todos os produtos com fotos e preços
3. Fazem o pedido direto no WhatsApp

Custa R$ 99 por mês - menos que um funcionário meio período.

Já temos [X] padarias usando e aumentaram as vendas em
até 30% no primeiro mês.

Posso mostrar como funciona?"
```

### Se Interessado
```
"Ótimo! Você tem 5 minutinhos agora ou prefere que eu
passe aí na padaria para mostrar no tablet?

[Se aceitar] Vou te mandar o link por WhatsApp, ok?
Qual é seu número?"
```

### Se Resistente
```
"Entendo! Deixa eu te fazer 3 perguntas rápidas:

1. Vocês têm cardápio no Instagram ou site?
   [Se não] Então você está perdendo vendas online!
   
2. Quantos pedidos vocês recebem por WhatsApp por dia?
   [Anote] Imagina aumentar isso em 30%...
   
3. Se eu te mostrar isso funcionando em 2 minutos,
   você toparia testar 30 dias grátis?
   [Se sim] Perfeito! Posso passar aí..."
```

### Marcar Visita
```
"Que dia e horário é melhor para você?
Amanhã às 10h ou depois de amanhã às 14h?

[Confirme]
Anota aí: [SEU NOME], [TELEFONE/WHATSAPP]
Qualquer coisa, me chama!"
```

## 🏪 VISITA PRESENCIAL

### 1. Chegada (Primeira Impressão)
```
- Vista-se bem mas casual (jeans + camisa)
- Leve tablet/notebook carregado
- Tenha demo pronta para mostrar
- Sorria e cumprimente educadamente
```

**Abertura:**
```
"Olá! Eu sou [NOME], ligamos ontem sobre o cardápio digital.
O(a) Sr(a) [NOME] está?"
```

### 2. Quebra-Gelo (1 minuto)
```
"Que padaria bonita! Faz quanto tempo que está aqui?
[Escute atentamente]

E vocês já trabalham com delivery/pedidos online?"
```

### 3. Identificar a Dor (2 minutos)
Pergunte:
```
"Deixa eu te fazer algumas perguntas:

1. Quantos clientes ligam perguntando preço e produtos?
   → [Problema: Perda de tempo]

2. Você perde vendas porque não tem cardápio online?
   → [Problema: Dinheiro na mesa]

3. É difícil atualizar preços quando muda?
   → [Problema: Trabalho manual]

4. Seus concorrentes têm site/cardápio digital?
   → [Problema: Competitividade]
```

### 4. Apresentar Solução (3 minutos)

**Abrir o tablet e mostrar:**

```
"Olha só como fica:

[Mostra landing page]
Esse aqui é um exemplo de padaria que já usa.

[Mostra cardápio]
Seus clientes vão ver tudo assim: fotos bonitas,
preços, descrições...

[Simula pedido]
Aí eles clicam aqui, escolhem os produtos, e...

[Mostra WhatsApp]
O pedido completo chega no seu WhatsApp!
Você só confirma e prepara.

Legal né? E olha o painel que VOCÊ usa:

[Mostra painel admin]
Aqui você adiciona produtos, muda preços, coloca
em promoção... Tudo em 2 cliques!
```

### 5. Apresentar Preços (1 minuto)

```
"E quanto custa? Você deve estar pensando que é caro né?

Não é! Tem 3 planos:

BÁSICO - R$ 49/mês
- Até 50 produtos
- Cardápio completo
- WhatsApp integrado

PROFISSIONAL - R$ 99/mês [APONTE ESTE]
- Produtos ilimitados
- Sistema de promoções
- Relatórios de vendas

EMPRESARIAL - R$ 199/mês
- Múltiplas lojas
- Suporte prioritário
- Tudo personalizado

Para a [NOME DA PADARIA], recomendo o Profissional.
São R$ 99 por mês - você gasta isso em 1-2 dias de
pães que sobram, né?
```

### 6. Lidar com Objeções

**"Está caro"**
```
"Entendo! Mas olha comigo:

R$ 99/mês = R$ 3,30 por dia
Isso é o preço de 1 café!

Se você vender apenas 1 pedido a mais por dia
(média R$ 20), você paga o sistema E ainda sobra!

E nossos clientes aumentam em média 8-10 pedidos/dia.
Faz as contas: 8 x R$ 20 = R$ 160/dia extra
= R$ 4.800/mês a mais!

Vale a pena investir R$ 99 para ganhar R$ 4.800?"
```

**"Preciso pensar"**
```
"Claro! Mas deixa eu te falar uma coisa:

Enquanto você pensa, seus concorrentes estão vendendo
online. [MOSTRE EXEMPLO DE CONCORRENTE SE TIVER]

Por isso eu ofereço 30 DIAS GRÁTIS!
Você não paga nada agora.

Eu configuro tudo hoje, você testa 1 mês inteiro.
Se não gostar ou não aumentar as vendas, é só cancelar.
Sem multa, sem pegadinha.

O que você acha? Vamos testar?"
```

**"Não sei mexer com tecnologia"**
```
"Perfeito! Por isso que é tão fácil!

[MOSTRE O PAINEL NOVAMENTE]

Veja: Adicionar produto = 3 cliques
Mudar preço = 2 cliques
Desativar item = 1 clique

É mais fácil que usar WhatsApp!

E eu faço toda a configuração inicial para você:
- Cadastro dos produtos
- Upload das fotos
- Configuração do WhatsApp
- Treinamento de 30 minutos

Você só vai usar pronto! E se tiver dúvida, me chama
no WhatsApp que eu ajudo na hora."
```

**"Meus clientes são velhos, não usam internet"**
```
"Eu entendo! Mas deixa eu te mostrar um dado:

70% das pessoas de 40-60 anos usam WhatsApp e
pesquisam no Google antes de comprar.

Seus clientes MAIS VELHOS também!

E sabe o que acontece? Eles veem seu concorrente
online e compram lá!

Além disso, você vai atrair clientes NOVOS - os
mais jovens que SÓ compram online.

É um investimento para não perder cliente velho
E ganhar cliente novo!"
```

### 7. Fechar a Venda (2 minutos)

**Técnica da Escolha:**
```
"Então, vamos fazer o seguinte:

Você prefere começar com o plano Profissional (R$ 99)
ou quer testar o Básico (R$ 49) primeiro?

[ESPERE A RESPOSTA]

Ótimo! E quando você quer que eu configure?
Hoje mesmo à tarde ou amanhã de manhã?
```

**Urgência:**
```
"Ah, e eu tenho uma promoção especial:

Para as primeiras 10 padarias que fecharem esta semana,
eu faço o SETUP GRÁTIS (valor R$ 200).

Isso inclui:
- Cadastrar todos os produtos
- Tirar fotos profissionais (se precisar)
- Configurar tudo pronto para usar
- 1 hora de treinamento

Mas é só até sexta-feira, depois volta ao normal.

E lembra: 30 dias grátis! Você só paga se gostar.

Bora fechar?"
```

### 8. Pós-Venda

**Se Fechou:**
```
"Parabéns pela decisão! Você não vai se arrepender.

Vamos fazer o seguinte:
1. Eu preciso de algumas informações [PREENCHER FORMULÁRIO]
2. Vou criar sua conta agora mesmo
3. Hoje à noite seu site já está no ar
4. Amanhã eu volto para te ensinar a usar

Me passa seu WhatsApp para eu te mandar os dados
de acesso, ok?

[TIRE FOTO COM O CLIENTE E PEÇA PERMISSÃO PARA DIVULGAR]

Muito obrigado! Você vai ver que vai valer a pena!"
```

**Se Não Fechou:**
```
"Sem problemas! Eu entendo que é uma decisão importante.

Deixa eu te deixar meu cartão e este material explicativo.

Qualquer dúvida, me chama no WhatsApp [NÚMERO].

E olha, a promoção do setup grátis vai até sexta-feira.
Se mudar de ideia, me avisa!

Muito obrigado pela atenção! Tenha um ótimo dia!"

[PEDIR PARA SEGUIR NO INSTAGRAM E DEIXAR CONTATO]
```

## 🔥 DICAS DE OURO

1. **Sempre mostre, não só fale**
   - Demo visual > palavras

2. **Use prova social**
   - "15 padarias já usam"
   - Mostre depoimentos reais

3. **Crie urgência**
   - "Promoção acaba sexta"
   - "Últimas 5 vagas"

4. **Ofereça garantia**
   - "30 dias grátis"
   - "Cancele quando quiser"

5. **Seja consultivo, não vendedor**
   - Entenda o problema
   - Apresente solução
   - Não force

6. **Follow-up sempre**
   - 80% das vendas vêm após 5+ contatos
   - Não desista fácil!
